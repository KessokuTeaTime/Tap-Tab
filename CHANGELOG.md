# Changelog

## 3.3.1

- Updated for Minecraft 26.1 through 26.1.2 and Java 25.
- Added Fabric and NeoForge support through Architectury.
- Ported hotbar animation, key bindings, tooltips, inventory swapping, and sounds to current APIs.
- Fixed the reversed next/previous sound registrations and switched animation timing to a monotonic clock.

## 3.3.0

- Unified publishing using ModPublisher.
- Changed artifact names from `{id}-{mcversion}-{modversion}` to `{id}-{modversion}-{loader}{mcversion}`.
- Changed tag names from `{id}-{modversion}-mc{mcversion}` to `{id}-{modversion}-{loader}{mcversion}`.
- Transferred ownership to [Kessoku Tea Time](https://github.com/KessokuTeaTime).
